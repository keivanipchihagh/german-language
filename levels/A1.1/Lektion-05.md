# Lektion 5 — Was ist das? – Das ist ein F

> **Topic:** Gegenstände, Produkte (Objects, products, colours, materials, shapes)
> **Book pages:** Kursbuch p. 29–32, action pages p. 84–85
> **Main grammar:** the **indefinite article** (*ein / eine*) and the **negative article** (*kein / keine*)
> **Main skill:** naming objects, asking for words, describing things, thanking, filling in a form

---

## 0. Overview

### Goals

After this lesson you can:

- Ask **what something is** and answer: *Was ist das? – Das ist ein Schlüssel.*
- Use **ein / eine** and **kein / keine** correctly.
- Ask for words: *Wie heißt das auf Deutsch? Wie schreibt man …?* and ask someone to **repeat**: *Noch einmal, bitte.*
- **Describe** an object: colour, material, shape.
- **Thank** someone and reply (*Danke. – Bitte schön.*) and **fill in an order form**.

### The story of this lesson

**Frau Paulig** is at the **eye doctor** and has to read letters from a chart: *„Das ist ein P. – Das ist ein F. – Das ist ein T."* Then a comic plays with the question **„Was ist das?"**: *„Ist das eine 8? – Nein. Das ist kein O. – Das ist auch keine 8. – Ja. Das ist eine Brille!"* The shop **Optik Eicher** offers designer glasses: *„Die Brille 'Ecozi' ist rund und aus Metall."* *„Sehr eckig und sehr elegant: das Designer-Modell '1-4-you' …"* In the second part, friends ask: *„Entschuldigung, wie heißt das auf Deutsch?"* – *„Das ist eine Uhr."* – *„Wie bitte?"* – *„Eine Uhr. U-H-R."* – *„Danke."* – *„Bitte schön."*

## 3. Grammar

### 3.1 ⭐ Main topic: the indefinite article *ein / eine*

Use **ein / eine** when you talk about **a** thing for the first time or without being specific ("a key", "a watch").

| Gender | Definite | **Indefinite** (nominative) | Example |
|---|---|---|---|
| **maskulin** | der Schlüssel | **ein** Schlüssel | Das ist **ein** Schlüssel. |
| **neutral** | das Buch | **ein** Buch | Das ist **ein** Buch. |
| **feminin** | die Brille | **eine** Brille | Das ist **eine** Brille. |
| **Plural** | die Schlüssel | – (no article) | Das sind Schlüssel. |

> 🧠 **Rules:**
> - **masculine & neutral:** *ein* (no ending). **feminine:** *eine*.
> - There is **no plural** of *ein*: use no article (*Das sind Brillen.*) or a number (*zwei Brillen*).
> - Use the **definite** article (*der/das/die*) for something already known: *Das ist ein Schlüssel. **Der** Schlüssel ist alt.*

### 3.2 ⭐ The negative article *kein / keine*

*kein* means **no / not a / not any**. It negates a **noun** that has *ein* or no article.

| Gender | Positive | **Negative** |
|---|---|---|
| **maskulin** | ein Schlüssel | **kein** Schlüssel |
| **neutral** | ein Buch | **kein** Buch |
| **feminin** | eine Brille | **keine** Brille |
| **Plural** | (–) Brillen | **keine** Brillen |

| Sentence | English |
|---|---|
| Das ist **kein** O. | That's not an O. |
| Das ist auch **keine** 8. | That's not an 8 either. |
| Das ist **kein** Buch. | That's not a book. |
| Ich habe **keine** Kinder. | I have no children. |
| Das sind **keine** Brillen. | Those aren't glasses. |

> 🧠 **ein → kein, eine → keine.** *kein-* has the same endings as *ein-*: no ending (m., n.), **-e** (f. and plural).

### 3.3 *kein* or *nicht*?

| Use | Rule | Example |
|---|---|---|
| **kein-** | negates a **noun** with *ein* or no article | Das ist **keine** Brille. · Ich habe **kein** Auto. |
| **nicht** | negates **verbs, adjectives, adverbs, names, nouns with definite article** | Das ist **nicht** schön. · Er kommt **nicht**. · Das ist **nicht** der Schlüssel. |

> 🧠 **Quick test:** If the positive sentence has *ein/eine* or no article → use **kein/keine**. If it has *der/das/die* or my/your → use **nicht**.
> - *Das ist ein Buch.* → *Das ist **kein** Buch.*
> - *Das ist das Buch.* → *Das ist **nicht** das Buch.*
> - *Das ist mein Buch.* → *Das ist **nicht** mein Buch.*

### 3.4 Definite vs. indefinite: comparison

| | Indefinite (new, "a") | Definite (known, "the") |
|---|---|---|
| masc. | ein Tisch | der Tisch |
| neutr. | ein Bett | das Bett |
| fem. | eine Lampe | die Lampe |
| pl. | Lampen | die Lampen |

> *Das ist **eine** Brille. **Die** Brille ist rot.* (first mention → *eine*; second mention → *die*)

### 3.5 *man* (one, you)

*man* is an impersonal pronoun: *Wie schreibt **man** das? · Wie heißt das auf Deutsch? · **Man** sagt „Uhr".* It takes the verb in the 3rd person singular.

## 4. Communication

### 4.1 Model dialogue: at the eye doctor

> **Arzt:** Frau Paulig, was sehen Sie hier?
> **Frau Paulig:** Das ist ein P.
> **Arzt:** Und hier?
> **Frau Paulig:** Das ist ein F. Und das ist ein T.
> **Arzt:** Gut. Sie brauchen eine Brille!

### 4.2 Comic: "Was ist das?"

> • Ist das ein O?
> ▲ Nein. Das ist kein O. Das ist eine 8!
> • Nein, das ist auch keine 8. Das ist … eine Brille!
> ▲ Ja. Das ist eine Brille.

### 4.3 Asking for a word

> • Entschuldigung, wie heißt das auf Deutsch?
> ▲ Das ist eine Uhr.
> • Wie bitte?
> ▲ Eine Uhr.
> • Wie schreibt man das?
> ▲ U-H-R.
> • Danke.
> ▲ Bitte schön.

### 4.4 Describing objects

> • Was ist das? – Das ist eine Uhr. Sie ist blau.
> • Das ist ein Telefon. Es ist rot.
> • Das ist ein Kugelschreiber. Er ist gelb.
> • Das ist eine Tasche. Sie ist braun und aus Leder.

**Game:** Draw an object on the board. The class guesses: *Ist das ein Buch? – Nein, das ist kein Buch.*

## 7. Common mistakes ❌ → ✅

| ❌ Wrong | ✅ Right | Why |
|---|---|---|
| Das ist **ein** Brille. | Das ist **eine** Brille. | feminine → *eine* |
| Das ist **eine** Schlüssel. | Das ist **ein** Schlüssel. | masculine → *ein* |
| Das ist **keine** Schlüssel. | Das ist **kein** Schlüssel. | masculine → *kein* |
| Das ist **kein** Brille. | Das ist **keine** Brille. | feminine → *keine* |
| Das sind **eine** Brillen. | Das sind Brillen. | no indefinite plural |
| Das ist **nicht** eine Brille. | Das ist **keine** Brille. | *nicht ein* → *kein* |
| Ich habe **nicht** Kinder. | Ich habe **keine** Kinder. | noun without definite article |
| Das ist **kein** schön. | Das ist **nicht** schön. | adjective → *nicht* |
| Wie heißt **das** Deutsch? | Wie heißt das **auf** Deutsch? | *auf Deutsch* |
| Wie **bitte**? (as thanks) | Danke. / Bitte schön. | check meaning |
| **der** Handy | **das** Handy | |
| Die Kette **sind** rot. | Die Kette **ist** rot. | singular → *ist* |
